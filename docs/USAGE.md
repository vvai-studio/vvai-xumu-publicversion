# 使用规范 · 序幕

这份规范写给**使用者**：怎么下需求、Agent 会在哪里停下来问你、产物放在哪里、哪些事情需要你单独授权。照着做，能少走很多返工。

> 技能内部的完整规则在 [`skills/xumu/SKILL.md`](../skills/xumu/SKILL.md)、`agents/`（身份与原则）和 `references/` 中，这里只讲你需要知道的部分。

---

## 1. 怎么触发

| AI | 触发方式 |
|---|---|
| 任意 AI（Claude、GPT、豆包等） | 直接用自然语言说「用序幕……」，AI 会自动调用（**推荐**） |
| Claude | `/xumu <你的需求>`；以插件方式安装时为 `/xumu:xumu`，输入 `/xumu` 可从菜单中选择 |
| GPT（Codex） | `$xumu <你的需求>` |
| 豆包 / 其他 AI Agent | 按该 AI 调用技能的方式，或直接用自然语言 |

**只提问不会开工**：如果你只是在问问题或讨论方案，它不会初始化项目、安装依赖或生成素材。要实际制作，请给出素材和目标。

**学习模式**：把喜欢的剪辑视频、风格案例或教程链接发给它，说"学一下"或"收进手法库"，它会拆解并归纳成手法卡，先给你确认再入库；以后做视频时按内容自动调用。

## 2. 一条好需求包含什么

```text
用序幕，
【素材】D:\素材\口播01.mp4
【平台】B 站横屏 16:9
【受众/目的】给 AI 初学者科普 Agent 是什么
【风格】知识区，干净克制，少量数据动效
【时长】3 分钟左右
【必须保留】结尾的三点总结
先给我制作方案。
```

四件关键信息：**平台、受众/目的、风格、时长**。缺了 Agent 会问，但它只问会实质改变结果的那几项，已经能推断的不会机械追问。建过频道档案之后，这四件大多不用再说。

### 频道档案与创作决策书

第一次用，Agent 会问三件事：做什么内容、发哪里、喜欢谁的片子。答完它在你的工作区建 `channel/`（品牌层：人像、配色、字体、声音、禁区；栏目层：一类内容的做法）。一个人可以有多个栏目，比如「AI 工具教程」和「周末记录」各一套风格。说「只做这一期」也可以不建。

之后每部片，Agent 先出一页**创作决策书**（`edit/创作决策书.md`）：

| 页 | 格 | 你要做的 |
|---|---|---|
| 归属 | 这期归哪个栏目，还是新建 | 点「对」或改 |
| 编剧页 | 有什么素材、脊梁（靠旁白 / 故事线 / 剧本 / 音乐串起来）、一句话、故事线、删留 | 认可故事线，或调顺序 |
| 导演页 | 风格方向（没想法时从不同大类给 3 个，各配画廊里的代表帧）、画面比例与节奏、声音、预算与自由度 | 点一个风格 |

**风格怎么选**：298 种风格每种有一张代表帧（装上就有，生图示意板或从参考视频截的帧，做过成片后换成真帧），推荐时直接贴图；其中 59 种开源风格包（`opuscar-` 开头）的代表帧是样片真帧，看板上点「看样片」能看整支样片。有喜欢的片子就发给它说「学这个风格」，它会把切点密度、运动量、色板和关键帧收进你本机的参考片库，以后推荐时排前；也可以说「照这个做」直接照参考做。

**故事线怎么排**：编剧会先拿你的「一句话」和素材去对 18 类组合配方（证据板讲清资讯、逐层递进讲清抽象概念、用真实任务证明产品价值、发布片情绪弧……），对得上就按配方的步骤起一版故事线给你看，每步写明镜头要达成什么、画面做什么、声音做什么；对不上就照常写。导演设计具体镜头时，转场、文字、声音这些局部手法会对照 64 项表达指导，把参数和检查问题写进镜头说明。

**自由度**：决策书第 9 格的 L0～L3 决定 AI 能发挥多少。L0 只用有模板的风格填空，L1 可以调色板字体和动作档位，L2 允许两成镜头从零定制，L3 不限。合成前有合规检查：自由度越界、风格不一致、出现禁用项会被拦下；阅读速度、动作档位、色板偏差只提醒。用弱一点的模型就把自由度调低，出来的片子更稳。

决策书第一行写明**当前模式**：全托（新手默认，只在故事线、风格方向、前 60 秒参考片三处停下来问）、半托（两页都给你看，默认通过）、专业（逐格确认）。说「你看着办」或「每步都问我」随时切换。

中途想换风格，Agent 会问清范围：只这一期 / 以后这个栏目都这样 / 新开一个栏目，默认只这一期。改动会记进 `channel/changelog.md`，以后推荐风格时不会把刚改掉的再推回来。

有参考就直接给：贴链接或发文件说「照这个做」，Agent 不再推荐，直接照参考拆风格；只学画面语言和节奏，不复制对方的素材、字体和音乐。

**模式决定后面哪些地方停下来问你**：全托只在参考片门停一次；半托在剪辑策略、画面方案、参考片门停三次；专业每个确认点都停。付费、渲染超过半小时、缺素材、要改叙事含义或主风格时，任何模式都会问。

**以前做过的项目**（只有 `project.md`）：再打开时 Agent 会问一次要不要从它的制作定位建档；说不用就不再问。

**本地看板**：进入创作板块时 Agent 可以起一个本机网页（Claude 桌面版直接在内置浏览器里打开，其他 AI 会把地址给你），五个页：创作决策书、频道档案、素材缩略图墙、风格画廊、镜头与确认点。能点的只有三样：选风格方向、确认某一格、过确认点（跳过要写理由）；改一句话、换故事线这些仍在对话框里说。说「不用看板」就不起。

### 输入模式

| 模式 | 你提供 | Agent 会做 | 注意 |
|---|---|---|---|
| **视频** | 口播视频 | 逐字转录 → 剪辑 → 局部覆盖镜头/MG → 字幕 → 合成 | 原片可以当全片背景，只在需要的地方加画面 |
| **音频** | 录音 / 播客 | 转录 → 选段 → 旁白母带 → **全片画面覆盖** | 不会自动加数字人（见下）；画面必须覆盖整片 |
| **文案** | 脚本 / 逐字稿 | 结构与分镜 → 选择旁白方式 | 原声后录 / 合成配音 / 无旁白，三选一 |
| **素材集** | 零散片段、照片、按剧本拍的多条 | 切镜头打分 → 缩略图墙 → 按故事线选段 → 粗剪预览给你看 | 分数只排除明显不能用的镜头，换哪段你说了算；有音乐时段长按拍取整 |

**数字人**：只在两种情况下做——你自己说要，或创作决策书第 7 格写明理由建议（比如没有出镜素材、栏目靠人脸建立信任）而你确认了这一格。照片必须是你本人或已取得本人同意的。默认可灵 4.0，台词由模型照文案说、你的克隆音色作参考，1 分钟 720p 约 20⚡；先跑一段样片给你看手势，你说可以再全量。拼好后按数字人实际说的话重新对齐字幕。音色像不像、口型对不对，需要你播放确认。

文案模式下，估算语速得到的时长只算**草案**；拿到实际音频后才锁定帧级时间，不会编造词级时间戳。

## 3. 流程与确认点

```text
0 创作决策书 ─▶ 1 剪辑/旁白策略 ─▶ 2 锁定主时间线 ─▶ 3 选镜头+整片节奏 ─▶ 4 分流制作 ─▶ 5 合成验收交付
   ✅ 确认点⓪        ✅ 确认点①                            ✅ 确认点②
```

| 阶段 | 你会看到 | 你需要做 |
|---|---|---|
| 0 创作决策书 | 编剧页 + 导演页一页纸；确认后合并成 `project.md` 的制作定位，每项标注来自本片 / 栏目 / 品牌 | **✅ 确认点⓪**：认可故事线、点一个风格 |
| 1 剪辑/旁白策略 | 删减哪些、顺序怎么调、声音怎么处理 | **✅ 确认点①**：同意后才会动刀 |
| 2 主时间线 | 有旁白：锁定旁白与帧级时长；Agent 不能亲自听时，会给你一段只含剪点和疑似卡壳处的「试听合集」。没旁白：素材缩略图墙 + 粗剪预览 | 听一遍指出哪处还卡（Agent 自己能听时无需操作）；没旁白时看预览说换哪段 |
| 3 画面方案 | 每段用人物 / Shotcraft 镜头 / 定制 MG 的理由，全片节奏，代表性静帧或动态样片 | **✅ 确认点②**：确认后 Agent 自主完成技术细节 |
| 4 分流制作 | 每个镜头先做小样验证，再正式渲染 | 无需操作（失败镜头不会进主片） |
| 5 合成交付 | 成片 + 可继续修改的工程/时间线 + 验收记录 | 看成片，提修改意见 |

**什么时候会重新找你确认**：改变叙事含义、主要风格、你指定过的镜头，或超出费用范围时。

**跳过逐段确认**：如果你明确说「视觉上你自己决定」，Agent 会把理由记录下来代替逐段确认，但外部服务权限和预算限制不会因此取消。

## 4. 产物放在哪里

- 有素材目录时：写在**素材目录下的 `edit/`**。
- 多个目录或纯文案、且你没指定位置时：默认 `outputs/<清晰项目名>/edit/`，开工前会先告诉你。
- **不会覆盖原素材**，也不会写进 skill 自身的源码目录。

```text
edit/
├── project.md          # 制作定位、确认记录、续作说明
├── edl.json            # 剪辑决定表（使用 Video Use 时）
├── visual-plan.json    # 唯一主时间线
├── assets.json         # 素材来源与授权
├── shots/<shot_id>/    # 每个镜头独立目录（定制 MG 附 brief.md）
└── verify/             # 验收证据
```

### 继续修改已有项目

把 `edit/` 目录指给 Agent 即可：

```text
这是上次的项目 outputs/ai-agents/edit/，第 3 章节奏改快一点，第 12 号镜头换成数据图表。
```

它会读取 `project.md` 沿用已确认的定位，时间线修订号 +1，只重算受影响的镜头和字幕，**不重转录未变化的源文件**。

## 5. 授权边界（重要）

制作授权**不包含**以下事项，每一项都需要你单独同意：

| 事项 | 规则 |
|---|---|
| 发布到任何平台 | 不会自动发布 |
| 克隆声音 | 默认不克隆你或任何第三方的声音 |
| 数字人 | 只在你要求、或决策书建议并经你确认时生成；只用本人或已获同意的照片；提交前要你对这一版配音的确认 |
| 上传素材到外部服务 | 需先确认具体服务和范围 |
| 付费生成（图像/视频/配音/配乐模型） | 先报价；在你自己设的免确认额度以内直接执行，超过才问 |
| 安装与任务无关的工具 | 不会安装 |

**API Key**：只放在环境变量或本地 `.env`，**不要**发给别人，也不会被写进计划、提示词或日志。

```bash
# 可选：启用 ElevenLabs 云端转录（带说话人区分）
export ELEVENLABS_API_KEY=你的key          # macOS / Linux
$env:ELEVENLABS_API_KEY = "你的key"        # Windows PowerShell
```

不会用终端时，让 Agent 打开密钥网页填写（`key_setup.py --var ELEVENLABS_API_KEY`）。没有 Key 时会自动改用本地免费的 faster-whisper，不会卡住。也可以用 Azure 快速转录（`AZURE_SPEECH_KEY` 加 `AZURE_SPEECH_REGION`）或阿里云 Fun-ASR（`DASHSCOPE_API_KEY`）。转录前 Agent 会用 `transcribe_cloud.py estimate` 列出各引擎的费用，你同意后才上传。注意：`skills/video-use/.env` 里写了 ElevenLabs Key 时，会优先走付费的 Scribe。中文想要更高准确率可设 `VV_WHISPER_MODEL=medium` 或 `large-v3`。

**生图、配音、配乐（可选，默认走造物社）**：对 Agent 说"配置 API"，它会按下面的步骤带你做：

1. 登录造物社，在「管理密钥」页新建一把密钥（只显示一次，先复制）。
2. Agent 会在浏览器里打开一个**只在本机的临时网页**（`key_setup.py`），你把密钥粘进去、点「验证并保存」就行，不用碰终端。它会先免费查一次余额，密钥对了才保存；保存后网页自动关闭，也不用重启你的 AI 工具。配好后新开窗口不用再填；以后换密钥，对 Agent 说"换密钥"，同样走这个网页。如果你的 AI 工具有沙箱、不允许保存，Agent 会申请在沙箱外运行，或给你一行命令贴到系统终端，只需做一次。密钥不要发到聊天里。
   习惯用终端的也可以自己设（把 `sk-你的密钥` 换成真密钥，设好后重开终端和 AI 工具）：
   ```bash
   setx VVAI_API_KEY "sk-你的密钥"                              # Windows
   echo 'export VVAI_API_KEY="sk-你的密钥"' >> ~/.zshrc          # macOS
   ```
3. Agent 运行 `audio_cloud.py setup` 列出要写入的默认设置（生图 GT Image 2.5 Flare 4K + 高质量、海螺配音、Suno 纯音乐），你确认后写入本机 `backends.local.json`；再用 `doctor` 免费检查余额和各项价格，`setup --smoke` 试跑一句配音和一张图（约 ¥0.14）。
4. 配音音色：有自己在造物社克隆的声音就用它；没有的话，Agent 会告诉你，并列出平台自带的音色（青涩青年、成熟女性、男性有声书、童声……），各合成一句给你试听再选。
5. 免确认额度默认 1.0：每次先报价，预计不超过这个数直接执行，超过才问你；改 `budget.confirm_over` 即可。

用别的服务商时，把 `skills/xumu/backends.local.example.json` 的 `audio` 段复制到 `backends.local.json` 自己填。没有配置时，Agent 会建议你自己录音或做无旁白的片子，不会悄悄改用其他免费引擎。

## 6. 素材与版权

- **本仓库不附带任何音乐/音效**。Shotcraft 原项目的 Mixkit 音频因许可证禁止再分发而被移除。请使用你**自己取得授权**的音频。
- 真实操作、真实结果优先用真实素材；不会用合成界面冒充证据。故事再现和概念示意会在记录中标明。
- 字体、图片、第三方素材请自行核对授权，记录在 `assets.json`。

## 7. 验收标准

1. `plan_tools.py check` 通过 = **结构正确**，不等于成片质量通过。
2. 必须看**真实渲染**：镜头内容、语义同步、字幕、人声、画面接缝。
3. 计划、样片、「仅通过编译」都**不能称作最终成片**。
4. 转录文字对得上、响度合规，**不等于听起来顺**。Agent 没有实际听过时，会写「待试听确认」，不会写「已修顺」。
5. 成片分辨率、方向不得低于原素材或约定规格（竖屏 1080×1920 起）：正式交付前跑 `deliver-check`，报告写进 `verify/`，不通过不交付。草稿/预览渲染（如 720p 草稿）文件名带「草稿/预览」字样，不当成片交付。

手动检查命令：

```bash
python skills/xumu/scripts/plan_tools.py check edit/visual-plan.json
python skills/xumu/scripts/plan_tools.py check edit/visual-plan.json --ready
python skills/xumu/scripts/plan_tools.py export edit/visual-plan.json --out edit/render-manifest.json
python skills/xumu/scripts/media_tools.py deliver-check <成片> --source <原素材> --report edit/verify/deliver_check.json
```

## 8. 常见问题

**Q：为什么我打 `/xumu` 找不到？**
A：Claude Code 插件安装时，调用名要带插件前缀：`/xumu:xumu`。冒号前是插件名，冒号后是 skill 名。输入 `/xumu` 会弹出补全菜单。

**Q：只装了 xumu 一个文件夹可以吗？**
A：不行。三个 skill 必须在同一个 `skills/` 目录，总控靠同级目录找到 video-use 和 video-shotcraft。

**Q：它会调用 HyperFrames 吗？**
A：只有在你**另外安装了** HyperFrames，且满足三种情况之一时才会调用：要求字幕放在人物背后、要的效果 Shotcraft 没有、需要配乐音效且你同意使用 HeyGen 账户。

**Q：能直接出成片吗？**
A：能，但需要本机有 Python、FFmpeg、Node.js 并能渲染。它是 Agent 工作流，不是双击即用的软件；每个项目的 Remotion 场景都按确认过的镜头现场实现并试渲染。
